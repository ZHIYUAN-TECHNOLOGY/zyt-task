## Intent (the W3 redesign)
- Quotation page, top to bottom: **What are you quoting?** (service-package cards: Port to door · Clearance only · Loose cargo · Forwarding · No package / custom) → **Who and where** (Client *, Port of Destination *, Attention, Validity, Containers; read-only chips Business type · Services on the order · Currency; Trailer Normal / Side-loader toggle when both are priced) → **Charges** (Charge · Unit · Qty · Price · Total + tariff badge + If req.; row ⋯ → Details… drawer; Cost and profit switch; Charge if required · Add Line · Reference Template) → **More details** fold (Route and parties · Cargo · Addresses · Package settings · Notes) → **Internal remark (never printed)**.
- Picking a package fills the charges from its tagged tariff rows, priced by the tariff floor's own resolver (a customer deal wins), quantities from Containers. **Replace package charges?** when lines exist; **Refresh package charges** re-prices. Locked under review, once approved/decided, or once cost lines are posted to the cost ledger.
- Header: audit controls (Submit for Review · Approve/Reject · Retract · Resubmit) → status badge → **Preview PDF** → one next-step button (Send on an approved unsent quote, Decide when sent, Convert to order when won) → **More ▾** (Export sheet ▸ EN/EN PDF/CN/Print page; Send/Resend; Decide; Convert to order; Correct decision; Post to cost ledger; Duplicate; Discard — each only where it applies) → **Save Quote**. Leaving with unsaved edits asks **Leave without saving?**.
- Fee templates: per-row **Packages** cell, **Tag all rows with…** (Add to every row / Remove from every row), list **Packages** column and **Package** filter. Tagging keeps an approved card approved.
- The exported sheet prints an **Attention / 收件人** row.
- Remark labels renamed: **Annotation (shown to the customer)** → **Note to customer (printed)**; **Quotation Remarks (internal — never printed)** → **Internal remark (never printed)**.
