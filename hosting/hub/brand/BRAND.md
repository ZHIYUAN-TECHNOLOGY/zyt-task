and chips `#0d1333`, border `rgba(139,154,232,.13)`, body text `#cdd6f5`, shadows
`rgba(0,0,0,.5–.6)`. Headings, muted, faint, accent and CTA stay as the site's dark values above.
Browser theme colour `#04061a`.

**Logo / icon navy** (sampled from the image files): lockup ≈ `#101c6c`, app-icon ground

## Type

- **Space Grotesk** — headings (`--grotesk`), fallback `"Segoe UI", system-ui, sans-serif`.
  Headings run tight: letter-spacing −0.02em to −0.045em.
- **Geist** — body (`--font-sans`), fallback `system-ui, sans-serif`.
- **JetBrains Mono** — code, numbers, labels (`--monoV2`), fallback `Consolas, monospace`.
- Nav links: 12 px, weight 500, uppercase, letter-spacing 0.17em; header 74 px tall,
  content max-width 1320 px.

## Shape and motion

Radius `18px` (`--radius`); tiles `16px`; small controls 10–12 px. Easing
`cubic-bezier(.16,1,.3,1)` (`--ease`).

## Naming

`ZYT · 致源科技` (application name), "Zhiyuan Technology" in full. Kota Kinabalu, Sabah,
Malaysia.
